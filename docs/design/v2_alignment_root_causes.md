# v2 字幕对齐：问题根因分析与重构方案

> 2026-10-18。背景：Shakira 马德里场 25 首精校后，审核时连续发现大量错误（字幕早 / 晚 1~2 s、整段没字幕、错位句、听错的词被当成字幕、幻听出俄语 / 法语）。之前是看到一处修一处，修一首坏一首。这里停下来按「策略」找根因，再决定怎么改。

## 1. 现在的流程（13 步）

| # | 步骤 | 做什么 | 依据 |
|---|---|---|---|
| 1 | align（concert_align） | 2.5 s 滑窗（每 0.5 s 一窗）送 Qwen 识别；每窗文字和每句歌词算相似度；DP 决定每一窗属于哪句；头尾窗口估开头结尾，MMS 在 ±1 s 内微调 | Qwen 窗口文字 |
| 2 | fill | 字幕之间「有人声没字幕」的空档整段送 Qwen，按标点切句，MMS 定时间；像某句歌词就用歌词写法 | 一次 Qwen 识别 |
| 3 | verify | 每句按自己的起止切出来送 Qwen，和字幕比，低于 45 分隐藏 | 一次 Qwen 识别（短切片） |
| 4 | drop | 复核只听到一个词的长句当错位去掉 | 第 3 步的识别 |
| 5 | expected | 补词段换成「按歌词顺序该在这里」的句子 | 第 2、3 步 + 再听一次 |
| 6 | snap | 补词段再听一遍，像哪句 Genius 就换成哪句 | 再听一次 |
| 7 | rescue | 被隐藏的句子带前后文再听，听得出就放回 | 再听一次 |
| 8 | adopt | 复核听到的和字幕不一样：短句换词 / 补漏词 / 连唱两遍 | 第 3 步 + 再听两次 |
| 9 | gaps | 没字幕的空档按歌词顺序补句子（读音键匹配窗口） | 第 1 步的窗口 |
| 10 | interj | 纯语气词句排进听到语气词的空档 | 第 1 步的窗口 |
| 11 | extend | 口号句往前延伸盖住前面的空档 | 人声能量 |
| 12 | split | 列举句一项一句，MMS 逐词 | MMS |
| 13 | lead | 统一提前 0.2 s | — |

第 2~12 步全是这两天为了修具体问题加的。

## 2. 根因

### 2.1 证据粒度不对：用「2.5 s 窗口像哪句」做分类，而不是把整首歌词和整首识别结果对齐

- 窗口文字很短，长句只露出一两个词也会被当成强证据：Waka Waka 开头人群喊「¡Vamos!」，DP 判成「Ahora vamos por todo」；BZRP 开头的「Ah, ah」判成「Por acá no vuelva', hazme caso」（全场 4 次都是这样）。
- 反过来，没有足够「像」的窗口就没有证据：单词句（Dale）、纯语气词句（Oh-eh-oh-eh）、拼写和读音差得远的词（zangalewa / Sangaleva）在 DP 里永远拿不到分，整段空着。
- 同一句唱好几遍（副歌、口号）时，窗口只知道「像这句」，不知道是第几遍，排序全靠 DP 罚分。
- 时间是从窗口反推的：开头 = 「最后一个还看得到开头词的窗口」和「第一个窗口」两种估计取中间，再 MMS ±1 s。窗口本身就有 2.5 s 宽，所以早晚 1~2 s 是这个方法的常态（Dale 早 2 s；改成别的估法又晚 2 s、和下一句顺序颠倒）。

### 2.2 一句一句、一段一段地局部决定，没有全局约束

- DP 之后的 11 步各自只看一个局部（某个空档、某一句、某个补词段），各有自己的阈值。它们之间互相影响：
  - 第 8 步把「Como tú sabe'」改成听到的「Como tú sabes, como tú sabes」后，第 9 步按 Genius 原文找不到这句，又补了一遍。
  - 第 2 步为了挡 BZRP 的法语幻听加了「强制按歌的语种再听一遍」，结果 Dai Dai（英语歌）里的西语句子「Juega como tú sabes」「Oe, oe, más fuerte」全被误杀，13 s 没字幕。
  - 第 7 步放回、第 4 步去掉、第 3 步隐藏，同一句可能被来回处理。
- 每条规则都是看着某一首歌的某一处定的阈值（0.4、0.5、0.6、0.75、72、80、85……），换一首歌就不成立。**这两天的修补本身就是问题的一部分**：每加一条规则修好一处，就可能改坏别处，而且没有办法知道改坏了哪里。

### 2.3 用「单次 Qwen 识别一个切片」去改字幕

- 第 2~8 步的依据都是「切一段音频送 Qwen 识别一次」。这有三个问题：
  - **短切片听错**：复核按字幕起止切，1~2 s 的切片拖长音、半个词，Qwen 常常听成别的（you're lookin' for → People，Zamina mina → Familia）。
  - **切片边界一变，结果就变**：切片的起止取决于上游的结果。上游任何一点改动（比如改了 Dai Dai 的对齐细节），GIRL LIKE ME 的空档边界就跟着变，送进 Qwen 的是另一段音频，识别结果就变了（1:37 那句三次跑出三个版本）。缓存只能保证同一段音频结果相同，挡不住这个。
  - **人群声 / 伴唱里幻听**：俄语、法语、「Thank you」、「em polo polo ou papai」都是这样来的。
- 这些不稳定的单次结果被直接用来**改字幕**（换词、放回、去掉），错误就被放大了。

### 2.4 「复核」既当裁判又当素材

- 逐句复核（verify）本来是用来检查的；现在它听到的文字又被拿来隐藏、去掉、放回、改词。裁判和被检查的东西用的是同一个不稳定的信号，所以没有独立的检查。

### 2.5 参考歌词和现场的差异没有被建模

- Genius 是录音室版。现场有删段、换序、重复、改词（GIRL LIKE ME 报国家名）、口号、观众合唱、伴唱、串烧。现在的做法是 DP 用跳句 / 跳段罚分硬套，套不上的再用识别补，补出来的又用各种规则修，没有一个统一的模型说明「哪些是歌词、哪些是现场多出来的、哪些歌词没唱」。

### 2.6 没有回归检查

- 每次改动只看正在看的那一首、那一处。你指出过的问题点（Dale 的时间、国家名一项一句、zangalewa ×4、BZRP 1:30 的歌词……）没有被记下来逐条复查，所以改坏了也不知道。

### 2.7 v1 的声学匹配（acoustic.py）在这场演唱会上分不清句子

v1 有两块声学：refine_timing（整首按顺序强制对齐，定时间）和 acoustic.py（用 MMS 的 CTC 概率「听」一段声音像不像在唱某句，不靠识别文字）。v2 一开始两块都没用。重构时把 acoustic 的打分拿回来当「裁判」，在 GIRL LIKE ME 上校准（每句的声学分减去同一段声音里其他歌词句的中位数 / 90 分位数）：

| 句子 | 实际 | 和其他句的中位数差 |
|---|---|---|
| Baby, you know I need no filter | 唱对 | +4.01 |
| Like it when I get so bossy | 唱对 | +3.00 |
| So they tell me…（0:56） | 唱对 | −0.23 |
| So they tell me…（2:01） | 唱对 | −0.76 |
| Latinas, latinas（错放在 1:23） | 错 | +1.07 |
| Sacúdelo como Shaki（错放在国家名中间） | 错 | +0.83 |

唱对的句子和配错的句子分数混在一起：人群声、混响、伴唱、人声分离的残留让声学模型分不清唱的是哪句。所以**声学只能用来给已知的句子定时间（强制对齐），不能用来判断唱的是哪句**；判断只能靠 Qwen 听到的文字。

## 4. 重构方案：一次全局对齐，代替 12 步修补

（实现：`workflow_v2/align2.py`，先用在 GIRL LIKE ME / Dai Dai / Waka Waka / BZRP；回归检查 `tests/regression_shakira.py`）

- 整首转写的块长：12 s 一块会把连唱两遍的句子合成一遍（GIRL LIKE ME 0:56~1:04 的第二遍「So they tell me」和「Ah-ah-ah, you're lookin' for」全丢了），改成 6 s 一块、每 3 s 一块
- 语气词表里不能有 la / na：西语冠词 la / las 被当成语气词，配到「Ayy, yeah」上
- 纯语气词句（Ayy, yeah / Oh-eh）只留紧挨着真歌词的：开场人群喊的 hey / uh huh 会被配上
- 声学（2.7）只定时间、记分数，不取舍

1. **整首连续转写 + 词级时间**：人声分成较长、互相重叠的块（如 15 s 一块、重叠 5 s）送 Qwen，拼接去重得到整首的词序列；再用 MMS 在人声上给这些词做强制对齐，得到每个词的时间。Qwen 只负责「唱了什么」，MMS 只负责「什么时候唱的」。块的切法固定（按时间均分），不依赖任何上游结果，所以结果稳定。
2. **歌词和转写做一次全局序列对齐**（词级、读音键相似度，允许整段重复 / 跳过 / 插入）：
   - 对上的歌词句：用 Genius 原文，开头结尾取对上的第一个 / 最后一个词的时间。
   - 歌词里没对上的句子：没唱，不出字幕。
   - 转写里连续一段没对上歌词：现场改词 / 即兴 / 口号，用转写文字出字幕，标「Qwen」。
   - 纯语气词、单词句、重复的副歌都在同一个对齐里按顺序处理，不再有专门的规则。
3. **时间统一处理**：每句开头 = 第一个词的时间 − 0.2 s；不和上一句重叠。
4. **逐句复核只用来标红**，不再改字幕、不再隐藏或放回。审核页的「Qwen 复核听到」列就是它。
5. **回归集**：把你在 GIRL LIKE ME / Dai Dai / Waka Waka / BZRP 上指出过的每个问题写成检查项（某句在某时间附近、某段要有某几句、某句不能出现……），每次改动先跑这 4 首，全部通过再跑全场。

要保留的：分段（segment）、人声分离、翻译、审核页、封面和投稿信息都不动；只换「精校字幕」这一段。
