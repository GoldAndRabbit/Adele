# 整场演唱会切单曲：按音乐切，不按歌词切（方案，2026-10-21）

## 现在的问题

现在的边界是「第一句 / 最后一句歌词 + 在空档里挑一个点」，只看人声，没看音乐。歌是从伴奏响起开始、到伴奏停下结束的，
前奏 / 尾奏没有歌词，于是：

| 例子（Lorde ACL 2026） | 现在 | 实际 |
|---|---|---|
| Broken Glass → Perfect Places | 切在 11:13（最后一句后 0.2 s） | 伴奏 11:15 才停（-14 dB 掉到 -42 dB），11:17～11:22 掌声，11:22 才开始讲话「Hey ACL」 |
| Current Affairs → Hard Feelings | 切在 36:46 | Current Affairs 的尾奏一直到 36:59（节拍还很强），37:00～37:13 是空档，37:14 Hard Feelings 开唱 |
| Favourite Daughter → The Louvre | 切在 The Louvre 第一句上 | The Louvre 的前奏被切给了上一首 |

## 原则

**一首歌 = 一段连续的伴奏**（含前奏、尾奏），**歌与歌之间 = 伴奏停下的空档**（掌声 / 讲话 / 安静）。
歌词只用来确认「这段音乐是哪首歌」，不用来定边界。

## 信号（都从已有的文件算，不用新模型）

- **伴奏** = 整场音频 − 分离出的人声（audio.flac − vocals.wav），每 0.5 s 一个响度（dB）
- **节拍性**：伴奏的起音强度在前后 3 s 里的周期性（自相关 0.3～1.0 s 的峰值）；音乐 0.4～0.6，掌声 / 讲话 0.1～0.3
- **人声**：分离出的人声响度；人声有、伴奏没有 = 讲话
- **歌词核心**：识别 + Genius 歌词对出来的每首「第一句～最后一句」（现在就有，可靠）
- 有转播歌名字幕时（Amazon 那种），OCR 的歌名时段直接用（现在就有）

## 算法

1. 每首歌的歌词核心定下来（识别对歌词，现有流程）。
2. 相邻两首的歌词核心之间，找**音乐空档**：伴奏比这首歌伴奏的中位响度低 12 dB 以上、或节拍性 < 0.3，持续 ≥ 1 s 的区间。
3. 上一首的**结尾** = 空档开始（音乐停的那一刻）+ 掌声尾巴（掌声开始减弱时，最多 8 s）。
4. 下一首的**开头**：
   - 空档里有讲话（人声有、伴奏没有），且讲话 ≤ 60 s：从讲话开始（讲话是给这首歌的开场白，归下一首）
   - 没有讲话：空档结束、伴奏重新响起的那一刻（前奏开始）往前 1 s
   - 讲话 > 60 s（Lorde 45:14～50:05 那段）：不归任何一首，下一首从讲话结束后的前奏开始
5. **连着唱、中间没空档**（串烧 / 无缝衔接）：在两首歌词核心之间，取伴奏响度最低、或和声 / 节奏变化最大的一点（chroma / 节奏的新颖度峰值）；
   都不明显就取中点，并标「需人工确认」。
6. 每个边界附带依据（音乐停在哪、掌声多长、有没有讲话、置信度），审核页上显示；不确定的标黄。
